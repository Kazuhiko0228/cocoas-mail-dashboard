一文定義

MEMORY LANEは、未来の自分が見たくなる瞬間に、今の自分が気づくためのサービス。
撮った写真を整理するのではなく、撮らなかったはずの瞬間を生み出す。

基本体験

QRを読み込む → Memoryに参加する → 自分だけのMissionが届く → Missionを頭の片隅に置いて一日を過ごす → 「今だ」と思った瞬間に撮る → みんなの写真・動画が集まる → AIが一つのMemory Movieを作る → 後日、参加者全員に届く。

3つの前提

撮る人にきっかけを渡す

「写真撮るよ」と言った瞬間に、残したかった自然な瞬間は消える。だから撮られる人ではなく、撮る人の頭の片隅に視点だけを置く。

人が瞬間を見つけ、AIが編集する

AIに写真を撮らせない。生成した映像も混ぜない。集まった素材から、誰もカメラを見ていない一枚を中心に一本へまとめるところだけをAIがやる。

同意は後付けの機能にしない

隠し撮りのためのサービスにはしない。参加していない人はMemoryに入らない。自分が写ったものは、理由を書かずにいつでも消せる。

MVPで証明すること

このサービスがあったから、本来なら存在しなかった写真・動画が生まれたか？
YESなら進む。NOなら、どれだけAI動画が綺麗でも失敗。
