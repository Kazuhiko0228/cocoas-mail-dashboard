01はじめに ── ログイン

EduGrow は、園から渡された3つで入ります。パスワードは、あなただけのものです。 アカウントの使い回しはできません（監査で「誰がいつ書いたか」を見られるためです）。

はじめてログインする全員

  1. 園コード（園ごとの合いことば）を入れる
  2. ログインID（半角の英数字）を入れる
  3. 園から渡されたパスワードを入れて「ログイン」を押す
  4. 「初回ログインです。ご自身のパスワードに変更してください。」と出たら、その場で自分のパスワードに変える
パスワードを忘れたら　園長・管理者に「作り直してください」とお伝えください。 前のパスワードが分からなくても作り直せます。ほかの人には教えないでください。

021日の流れ

上から順に押していけば、その日の記録はそろいます。 保存ボタンはありません。入れたそばから自動で保存されます。
出勤タブレット
玄関のタブレットで打刻する
ホームの「打刻」を押す → テンキーで自分の4けたを入れる → 名前が出たら「出勤」。「◯◯さん　08:05 出勤で記録しました。」と出れば終わりです。
出てきた名前がちがうときは「やめる」を押して、番号から入れ直してください。
朝9時ごろ
登園（出席）をつける
「保育記録 → 日常チェック」を開き、上のチップが登園（出席）になっていることを確かめます。 日付とクラスを選び、天気・室温・湿度を入れます。
園児ごとの出欠ボタンは、押すたびに — → ●（出席）→ 早（早退）→ 遅（遅刻）→ 休（欠席） と変わります。
保護者から欠席・遅刻の連絡が届いている子は、空欄に自動で入り「保護者」の印が付きます。 先生が入れた印は書き換えません。食いちがうときは赤い印が出ます。
検温登園のとき
体温を入れる
体温計をつないでいれば、出欠を「●」にした瞬間に検温がはじまり、その子の欄に入ります。 つないでいないときは「体温」の欄に 36.5 のように直接入れてください。
37.5℃以上の子がいると、表の下に赤字で名前が出ます。
午睡お昼寝
午睡チェックをつける
同じ画面の下にあります。時刻ごとに、担当の先生を選び、眠る向きを矢印（↑→↓）で入れます。
国の目安の間隔は 0歳＝5分に1回／1〜2歳＝10分に1回／3歳以上＝15〜30分に1回。 そのクラスの目安が画面にも出ます。気づいたことはメモ欄へ。
その日あったとき
できごとを残す
けが・発熱・ひやりとしたことは 事故・ヒヤリハットの記録 へ。 成長で気づいたことは 児童票（成長の記録） へ。 保護者とのやり取りは 保護者対応の記録 へ。
その日のうちに一言でも残してください。あとから思い出して書くと、監査で「本当にその日か」を問われます。
夕方書き終わり
「この記録を確定する」を押す
黄色い帯に「まだ確定していません」と出ているうちは、監査で「承認が押されていない」と見られます。 書き終わったら必ず押してください。
登園（出席）を確定すると、午睡チェックと健康チェックにも同じ印が自動で付きます。
退勤タブレット
打刻して帰る
ホームの「打刻」→ 4けた → 名前の下に「出勤 08:05」が出ていることを確かめて「退勤」。
時刻はボタンを押した「いま」が入ります。あとから時刻を選ぶことはできません。

03記録は「確定」して終わり

監査でいちばん見られるのが、ここです。 確定を押していない記録は、書いていないのと同じに見られます。

確定する全員

  1. 記録を書き終える（自動で保存されています）
  2. 画面いちばん上の黄色い帯の右にあるこの記録を確定するを押す
  3. 「確定したあとは読むだけになり、直すには園長・管理者の許可が要ります。」に OK
  4. 帯が緑になり「確定ずみ　日時　あなたの名前」と出れば終わり
  • 1文字も書いていない記録は確定できません。
  • 身体測定だけは「保存する」と「確定する」が別です。

確定したあとに、直したいとき許可は園長・管理者

  1. 園長・管理者に「◯月◯日の△△を直したい」と伝える
  2. 園長・管理者が、その記録の緑の帯の修正を許可を押す
  3. 帯が「きょうのうちだけ直せます」に変わり、書けるようになる
  4. 直したら、帯の直し終わったを押して閉じる
許可はその日のうちだけです。日付が変わると自動で閉じるので、翌日はもう一度お願いしてください。
直したところは全部残ります。紙に出すと、直す前が灰色の取り消し線、直したあとが赤字で並びます。 これは疑われないための仕組みです。堂々と直してください。

紙に出す全員

  1. 記録の画面で、出したい日付（身体測定・児童票は月）を選ぶ
  2. 右上の印刷ボタンを押す（登園なら「名簿シートを出力」）
  3. まとめて出すときは、画面いちばん下の「期間をまとめて出力」で開始日・終了日を入れて「まとめて印刷」
紙の下には、園名・出力日・確定した日時と人・直した跡がかならず付きます。 記録の無い日は出ません。監査当日は、この「まとめて印刷」がいちばん早いです。

04保護者への連絡

ひとりの保護者に送る全員

  1. 「連絡・配信 → 保護者DM」を開く
  2. 左の一覧から、その園児のやり取りを選ぶ
  3. 下の欄に書いて送る

クラス全体・園全体に送る全員

  1. 「連絡・配信 → 全体周知・お知らせ」を開く
  2. 送り先（クラス・全体）を選ぶ
  3. 文面は「メールテンプレート」で園が作ったものから選べます
送ったものは取り消せません。送る前に、宛先と園児名をもう一度お確かめください。

05困ったとき

打刻で「この番号の先生が見つかりません」と出る
暗証番号が登録されていません。園長・管理者に決めてもらってください。 番号そのものは端末に残らないので、忘れたときは決め直しになります。
打刻で「この番号は複数の先生に登録されています」と出る
別の先生と同じ番号になっています。園長・管理者に番号を分けてもらってください。
「出勤」ボタンが押せない
その日もう出勤を押しています。「退勤」が押せないときは、まだ出勤を押していません。
記録の欄に書き込めない
その記録は確定ずみです。帯に「直すには園長・管理者の許可が要ります」と出ているはずです。 園長・管理者に「修正を許可」を押してもらってください。
開こうとした画面が「このアカウントでは開けません」と出る
その画面は先生には渡されていません（お金・監査・営業の画面など）。 必要なときは園長・管理者に、設定 → 権限管理 から渡してもらえます。
園児の名前が一覧に出てこない
その曜日に通う予定がない子、または休園中の子は出ません。 記録や保護者からの連絡がある子は、かならず出るようになっています。
まちがえて送ってしまった
すぐに園長へ。保護者DMなら、続けて訂正をお送りするのがいちばん早い対応です。
