2. 取得する情報（ご入力いただくもの）

  1. 利用者の方について：お名前、メールアドレス、電話番号、パスワード（暗号化して保存します）。
  2. 児童について：お名前、生年月日、所属する園・クラス、ご住所。
  3. 園連携情報：所属園、クラス、出欠、連絡、成長記録、身体測定、健康情報、書類その他、園との連携により取り扱われる情報（規約第2条6号）。
  4. 健康に関する情報：アレルギー、既往症、服薬、けが・体調の記録。これらは法律上の「要配慮個人情報」にあたります（第4項をご覧ください）。
  5. 画像：児童の写真、園が配信する写真。
  6. 取引に関する情報：注文内容、金額、お届け先、参加されるイベント、お支払方法に関する情報。
  7. 投稿情報：コミュニティへの書き込み、商品・イベントへの評価と口コミ（規約第2条7号）。
  8. お問い合わせ：AIサポートおよび有人サポートへのご質問の内容。

3. 取得する情報（ご利用にともなって自動で記録するもの）

  1. 匿名の家庭ID：ご家庭を数えるための記号です（例 h1konqtd）。お名前からは作らず、このIDからご家庭をたどることはできません。
  2. 行動の種類：お知らせ閲覧、コンテンツ閲覧、いいね、保存、商品閲覧、購入、イベント申込、画面の表示。
  3. 対象：ご覧いただいたコンテンツ・商品の番号と分類、その発信者（園／教育事業者／未来WA）。
  4. 端末：スマートフォン／タブレット／パソコンの別と、基本ソフトの種類。
  5. セッションID：一度のご利用をひとまとまりとして数えるための記号です。ブラウザを閉じると消えます。
  6. 上記の操作が行われた日時。
  7. IPアドレス、位置情報、広告識別子は取得していません。

4. 要配慮個人情報（健康に関する情報）

  1. 当社は、児童の病歴、アレルギー、障害、健康状態その他、法令上「要配慮個人情報」にあたる情報を取り扱うことがあります。
  2. これらを取得し、また園その他の第三者へ提供する場合、当社または園は、入力または連携の前に、利用目的、情報の項目、提供先および利用方法を画面に表示し、ご本人または必要な権限を有する保護者の方から同意をいただきます（規約第7条6項）。
  3. 利用規約への包括的な同意のみをもって、これらの情報の取得に同意いただいたものとはしません（規約第23条3項）。
  4. これらの情報は、児童の安全および健康の管理に必要な範囲でのみ取り扱います。
  5. 同意はいつでも撤回できます。ただし、撤回により園の業務に必要な情報が不足し、本サービスの一部をご利用いただけなくなる場合があります。

5. 児童の情報と、登録する権限

  1. 児童本人のアカウントは作成しません（規約第2条3号）。
  2. 児童に関する情報は、親権者、未成年後見人その他、登録および提供に必要な権限を有する方にご提供いただきます（規約第5条）。
  3. 当社は、児童の安全、権利の保護または不正利用の防止のため合理的に必要な場合、本人確認資料、権限を確認できる資料または園による確認を求めることがあります。
  4. 児童の顔が判別できる画像は、必要な権限を有する保護者の方の個別の同意がない限り、本サービスの提供以外の目的（広報・宣伝など）には使用しません（規約第13条2項）。

6. 園およびEduGrowとの関係

  1. 園連携情報のうち、園から委託を受けて当社が取り扱うものについては、園との契約および園の適法な指示の範囲で取り扱います。この部分は園が管理します。
  2. ショップ、イベント、コミュニティ、AIサポートおよびご利用状況の記録は、当社が自ら管理します。
  3. EduGrow は、園が園務の管理および保護者の方へのご連絡に利用する当社のシステムです。本サービスと連携し、園連携情報はこの連携を通じて表示されます。
  4. 園における取扱いは、園の定めによります。園が管理する情報に関する開示等のご請求は、園へお願いします。
  5. 卒園、退園、転園、園との契約終了その他の事由により園連携が解除された場合、当社は、園との契約、法令および本ポリシーに従い、園から委託を受けて取り扱う情報について、削除、返却、利用の停止または必要な期間の保管を行います（規約第7条5項）。

7. 第三者への提供

  1. 出品者等へ：ショップでご購入いただいたとき、発送に必要な範囲で、お名前、ご連絡先、お届け先および注文内容をお渡しします。商品は出品者等からお客さまへ直接お届けします。
  2. 主催者へ：イベントにお申し込みいただいたとき、受付に必要な範囲で、お名前、参加される児童のお名前と年齢およびご連絡先をお渡しします。
  3. 決済事業者へ：お支払いに必要な範囲でお渡しします。決済に必要な情報の取扱いは、当該事業者の規約および本ポリシーに従います（規約第9条3項）。
  4. 園へ：園と連携されている場合、出欠・連絡、申請、書類その他の情報を送信します。
  5. スポンサーへ：利用者または児童を識別できる個人データは、法令に基づく場合または別途同意をいただいた場合を除き、提供しません。個人を識別できない集計・統計の情報を提供することがあります（規約第17条3項）。
  6. このほか、法令に基づく場合、人の生命・身体・財産の保護のために必要でご本人の同意を得ることが困難な場合、公衆衛生の向上または児童の健全な育成のために特に必要な場合、国の機関等に協力する必要がある場合には、同意なくお渡しすることがあります。

8. 利用目的

  1. 本サービスの提供、本人確認およびアカウントの管理。
  2. 園からのお知らせ・おたよりの配信、出欠・連絡の受付と園へのお伝え、成長記録の表示。
  3. 商品の販売、代金の請求と決済、発送、イベントの受付。
  4. コミュニティの運営、投稿情報の表示・保存・バックアップ。
  5. お問い合わせへの対応、および不具合の調査。
  6. ご利用状況を統計的に分析し、本サービスおよび園の運営を改善すること。
  7. 不正利用の防止および安全の確保。
  8. 法令に基づく対応。

9. 業務の委託

  1. 利用目的の達成に必要な範囲で、サーバの運用・保守、決済の代行、商品の配送、AIサポートの提供、お問い合わせ対応の一部を外部に委託することがあります。
  2. 委託先には、契約により安全管理を義務づけ、監督します。

10. 外国にある第三者への提供

  1. 本サービスのサーバは、Railway（米国の事業者）の設備を利用しています。データは同社の設備に保存されます。
  2. 米国は、個人情報保護委員会が指定する「本人の権利利益を保護するうえで我が国と同等の水準にあると認められる個人情報保護制度を有している外国」には指定されていません。
  3. 同社は、契約上の安全管理義務を負い、暗号化された通信および保存、アクセス権限の管理その他の保護措置を講じています。［提供先が講じている措置の詳細は、確認のうえ記載します］
  4. 上記の取扱いについては、ご登録の際にあらためて同意をいただきます。［同意の取得方法は実装にあわせて確定します］

11. ご利用状況の記録

  1. どの記事が読まれ、どの教材が選ばれているかを集計し、園と当社のサービス改善に使います。
  2. 記録に、お名前・メールアドレス・電話番号は含みません。
  3. ご家庭は匿名のIDでのみ数えます。このIDは、お使いの端末ごとに作られる値と児童の登録番号から作られ、IDから元の情報を復元することはできません。
  4. この記録を、広告の配信や、ご本人を特定する目的に使うことはありません。
  5. マイページの「ご利用状況の記録」から、いつでもお止めいただけます。お止めになっても、機能はこれまでどおりお使いいただけます。

12. AIサポートの記録

  1. ご質問の文面を記録します。ただし記録する前に、園に登録されている児童・保護者の方のお名前、メールアドレスおよび電話番号を ○○ に置き換えます。
  2. あわせて、ご質問を「AIが24時間回答したもの」「AIで解決できず担当者へ引き継いだもの」「個人情報・誤配信に関するもの」「システム障害など緊急のもの」「機能のご要望」に分類して記録します。
  3. 当社は、利用者または児童を識別できる情報を、ご本人または必要な権限を有する保護者の方の同意なく、第三者が提供する汎用のAIモデルの学習目的で提供しません（規約第16条6項）。

13. Cookie・端末識別子・外部送信

  1. 現在、広告または分析のための外部への送信は行っていません。
  2. セッションIDは、お使いのブラウザの中にのみ保存され、ブラウザを閉じると消えます。
  3. 将来、外部のサービスを利用する場合は、送信先、送信する情報および利用目的をあらかじめお知らせします。

14. 安全管理措置

  1. 組織的：責任者の設置、取扱い記録の保存、事故時の報告体制の整備。
  2. 人的：従業者への教育、秘密保持義務。
  3. 物理的：端末の管理、持ち出しの制限。
  4. 技術的：通信の暗号化、パスワードの暗号化保存（PBKDF2-SHA256・15万回）、役割に応じた表示および通信の制限、保護者の入口と園の入口の分離。
  5. 外的環境：サーバの所在国（米国）の制度を踏まえた措置。第10項をご覧ください。

15. 保存期間と削除

  1. アカウントおよび児童の基本情報：退会または園連携の解除から［要確定］か月。
  2. 園連携情報：園との契約および園の定めによります。
  3. ご購入の記録：法令に基づき7年。
  4. ご利用状況の記録：13か月。
  5. AIサポートの記録：12か月。
  6. 投稿情報：削除または退会の後も、法令上の保存、紛争対応、セキュリティ、バックアップの循環消去、他の利用者との会話の維持その他合理的に必要な範囲で、一定期間保持される場合があります（規約第13条3項）。
  7. 期間の経過後は、復元できない方法で削除し、または匿名化します。

16. 開示・訂正・利用停止のご請求

  1. 保有個人データについて、開示、訂正、追加、削除、利用の停止、消去、第三者提供の停止および第三者提供記録の開示をご請求いただけます。
  2. 窓口：info@bimjapan.jp
  3. 本人確認書類（親権者の方であることが分かるもの）をご提示ください。
  4. 手数料：［要確定］　回答までの期間：［要確定］営業日以内。
  5. 園が管理する情報については、園へご請求ください。

17. 漏えい等が起きたとき

個人データの漏えい、滅失、毀損その他の事態が生じた場合、法令に従い、個人情報保護委員会への報告およびご本人へのご連絡を行います。

18. 本ポリシーの改定

  1. 本ポリシーを変更する場合は、本サービス上に掲示します。
  2. 重要な変更については、あらためて同意をいただくことがあります。
