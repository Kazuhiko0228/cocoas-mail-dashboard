未来WA ／ 園の管理者向け

未来WA 管理者の手引き

未来WA は、保護者の方がスマートフォンで使うアプリです。 園からの連絡・連絡帳・行事のカレンダー・お子さまの記録・教材やイベントが、ここに集まります。
園の操作は、すべて Miralink の画面から行います。保護者にアプリを届けるところから、 日々の運用、聞かれたときの答え方までをまとめました。
Miralink　／　2026年11月版

01はじめる ── 保護者にアプリを届ける

未来WA は、保護者がログインできて、はじめて動きだします。 アカウントはご家庭に1つです。同じメールアドレス・同じ名字のごきょうだいは、1つのアカウントで全員見られます。 操作はすべて「未来WA → 未来WA」の上のタブ保護者アカウント新規発行から行います。

招待メールを送る（メールのあるご家庭）管理者だけ

  1. 「まとめて招待する（メール）」に、まだアカウントの無いお子さまと、生徒情報のメールアドレスが並びます
  2. 送るご家庭にチェックを入れ、選んだご家庭に招待メールを送るを押す（ごきょうだいは1通にまとまります）
  3. 保護者はメールのリンクを開き、ご自身でパスワードを決めます。ログインIDはそのメールアドレスです
園がパスワードを考える必要はありません。リンクは7日間・1回だけ使えます。
期限が切れたときや届いていないときは、その家庭の行の招待を送り直すを押します。前のメールのリンクは使えなくなります。
生徒情報にメールアドレスが無いお子さまは選べません。下の「紙で発行する」をお使いください。

紙で発行する（メールの無いご家庭）管理者だけ

  1. 同じカードの下の「メールの無いご家庭は、紙で発行する」で園児を選ぶ（生徒情報にメールアドレスがあれば、自動で入ります）
  2. 保護者のメールアドレスとはじめのパスワード（8文字以上）を入れて発行する
  3. 「未来WA ご利用案内」の紙が出ます。印刷するかPDFで保存をして、ご家庭にお渡しする
紙には、未来WAを開く二次元コード・メールアドレス・はじめのパスワードが載ります。園コードは要りません。
パスワードが載るのは、このときだけです。あとから行の案内を出すで出し直せますが、パスワードの欄は空になります。
園児を選ぶ欄には、アカウントの無いご家庭のお子さまだけが並びます。二重に発行してしまうことはありません。

まだ入っていない家庭を見つける管理者だけ

  1. カードの上に「◯家庭が、まだ一度も入っていません」と出ます。その家庭の行にも同じ言葉が出ています
  2. 招待メールを送った家庭には「招待メールを送りました（日付）」「期限（7日）が切れました」「送れませんでした」のどれかが出ます
  3. IDが渡っていないか、入りかたが分からずにいるかもしれません。声をかけてください

パスワードを忘れた、と言われたら管理者だけ

  1. その家庭の行のパスワードを作り直すを押す
  2. 新しいパスワード（8文字以上）を入れる。いまのパスワードは分からなくて構いません
  3. 新しいパスワードが載った案内の紙が出ます。印刷するか保存して、保護者にお渡しする
これまでの注文・申込・連絡の記録は、そのまま残ります。

卒園・退園したとき管理者だけ

  1. その家庭の行の止めるを押す
  2. 保護者は未来WAに入れなくなります。記録は消えません
  3. 戻ってこられたときは、同じ行の戻すを押すだけです

02ふだんの運用 ── 園から保護者へ

保護者は未来WAのアプリ1つで受け取ります。 送る操作は、すべて Miralink の画面から行います。 「未来WA → 未来WA」の「未来WAとは？」にも、何が保護者へ届くかの一覧があります。

おたより・お知らせ連絡・配信 → 全体配信・お知らせ
園からの個人メッセージ連絡・配信 → 保護者DM
連絡帳（園からの連絡）連絡・配信 → 保護者連絡・連絡帳
園のカレンダー（行事）連絡・配信 → 保護者カレンダー
体温・体調・午睡の時間毎日記録 → 登園（出席）（出席簿・健康チェック・午睡チェック）

お知らせが保護者に出てこない、と言われたら全員

  • お知らせは、状態が「公開」のものだけが保護者に出ます。予約した配信は、その日時まで届きません（「予約済み配信」に並びます）。
  • 保護者DMは、下書き・園内の申し送りは届きません。送信済のものだけです。
  • ご請求は「送付済」「入金済」になってはじめて保護者に見えます。 「発行済」の段階では、まだ見えていません。
  • 園のカレンダーは、下書きに保存しただけでは出ません。「未来WAに配信」を押したものだけです。
「届かない」の相談は、まずこの状態を見てください。

保護者から届いたものを受け取る全員

  1. 欠席・遅刻・お迎え時間の変更　毎日記録の登園（出席）に、空欄のときだけ自動で入り「保護者」の印が付きます
  2. 登園・降園　保護者が未来WAで押した時刻（またはQRコードを読んだ時刻）が、出席簿に入ります
  3. 連絡帳（おうちでの様子）　連絡・配信 → 保護者連絡・連絡帳 に届きます
  4. 保護者からのメッセージ　保護者DM に届きます
  5. 教材の注文・イベントの申込　未来WA の「売れたもの」「イベント」に届きます
先生が入れた出欠の印は、保護者からの連絡で書き換わりません。 食いちがうときは「連絡は欠席」のような赤い印が出ます。どちらが正しいかは、園でご判断ください。

行事のカレンダーを配信する全員

  1. 「連絡・配信 → 保護者カレンダー」を開く
  2. 予定を追加（または日付を押す）で、予定の名前・日付・出すご家庭（全家庭／クラス）・場所・持ち物・スタンプを入れて下書きに保存
  3. 上の未来WAに配信を押し、確かめの窓で配信する
配信すると、未来WAの「園のカレンダー」に出て、おたより・お知らせに「園のカレンダーを更新しました」と届きます。 クラスを選んだ予定は、そのクラスのご家庭にだけ出ます。消した予定は、次に配信したときに消えます。
園の月間カレンダー・年間スケジュールとは別のものです。

登園・退園の方法を決める園長・管理者

  1. サイドバーの「登園・退園」を開く
  2. 「登園・退園の方法」で、両方／QRコードだけ／ボタンだけから園全体で1つ選ぶ
  3. QRコードを使うときは、玄関の端末でこの画面のはじめる（全画面）を押し、開いたままにする
保護者の未来WAの画面も、これに合わせて変わります。QRコードは、その日の1回目が登園、2回目が降園です。

相談窓口を知らせる・アンケートを配信する園長・管理者

  1. 「職員情報 → こども性暴力防止」を開く（園の条件で対象の園にだけ出ます）
  2. 「相談窓口」に、園の相談員の名前・相談のしかた・外の相談窓口を入れる。入れた名前と連絡先は、未来WAのマイページに出ます
  3. 「保護者へのアンケート（未来WA で配信）」で問いを確かめ、締め切りを決めて未来WA で配信する
  4. 配信中は「回答受付中」と回答の件数が出ます。終えるときは受付を締め切る
アンケートは全家庭のマイページに出ます。回答はお名前と一緒に届き、見られるのは園長・管理者だけです。 締め切ると未来WAに出なくなり、いただいた回答は残ります。

03未来WA の画面 ── 教材・イベント

「未来WA → 未来WA」の「未来WAとは？」の下に、スクール用 未来WAがそのまま出ています。 商品を出す・イベントを出す・売れたものを見る、はこちらの画面です。

教材・用品を出品する全員

  1. 左の一覧から「ショップ出品」を開く
  2. ＋ 商品を出品を押す
  3. カテゴリ・商品名・説明・価格を入れる
  4. 「売り方」を選ぶ（単品で売る／毎月おとどけ／貸し出す）
  5. 園だけの欄「ねらい」「今月のおすすめ」「見せる相手」「写真」を入れる
  6. 公開する、またはまだ出さないなら下書きに保存
下書きのつもりでも、状態を入れずに保存すると保護者に見えます。 出したくないものは、必ず「下書きに保存」を選んでください。

園のおすすめを、保護者のストアのいちばん上に並べる全員

  1. 「ショップ出品」の上のほうの「園のおすすめの並び」の表を見る
  2. 出したい商品の「見せる」にチェックを入れ、「順番」に数字を入れる
  3. 必要なら「ご用意のお願い」（例：入園までにご用意ください）を書く
  4. この内容で保護者に見せるを押す

イベントを出す・申込の名簿を見る出すのは全員／名簿は園長・管理者

  1. 「イベント」を開き＋ イベントを作成
  2. 対象者（親子／保護者向け／子供向け）、テーマまたは種別、対象の年齢を選ぶ
  3. タイトル・内容・開催日・定員・場所・参加費を入れて公開する
  4. 申し込みは、そのイベントの行の申込の名簿で見られます
お申し込みのお名前が見られるのは園長・管理者だけです。先生には件数だけが出ます。

売れたものを確かめて「受け取りました」を押す全員

  1. 「売れたもの」を開く
  2. 売れた金額・園への還元・まだ確認していない注文の数を見る
  3. 注文の明細で、日時・園児・商品・金額を確かめる
  4. 品物が園に届いたら、その行の受け取りましたを押す
この操作をすると、保護者の画面が「園で受け取りました」に変わります。 押さないと、保護者はいつまでも「園の確認待ち」のままです。
園への還元率（0〜50）も、この画面で決めて保存します。

ダウンロード教材のファイルを預ける園長・管理者

  1. 商品のカテゴリを「ダウンロード教材」にして、先に公開または下書きに保存する
  2. その商品を「編集」で開き直し、「お渡しするファイル」でPDF・PNG・JPEG（4MBまで）を選ぶ
  3. 「お渡しできる日数」と「受け取れる回数（1家庭）」を入れる
  4. このファイルを預けるを押す
預けられるのは園長・管理者だけです。先生の画面では断られます。
保護者は、その教材を買った家庭だけが受け取れます。

04保護者に聞かれたら

保護者のアプリには、5つのタブ（花びら）が並んでいます。 🏫スクール／🎨あそぶ／🌱まなぶ／🛍️ストア／🤝つながる。 園に関することは「スクール」に集まっています。上から、登園・降園／連絡帳／出欠・連絡／園のカレンダー／園からの個人メッセージ／写真／おたより、の順です。
ログインには何を入れますか
メールアドレスとパスワードの2つだけです。園コードは要りません。 招待メールで始めたご家庭は、メールのリンクでご自身が決めたパスワードです。
おやすみの連絡は、どこからしますか
「🏫スクール」タブの「📅出欠・連絡」です。 日付と区分（欠席／送迎時間変更）を選び、事情を書いて送っていただきます。 送った控えと園からの返信は、その下の「🗒連絡の履歴」に残ります。
登園・降園は、どうすればいいですか
「🏫スクール」タブのいちばん上「🚸きょうの登園・降園」です。 園の設定により、ボタンを押すか、「登降園のQRコード」を園の入口の端末にかざします（1回目が登園、2回目が降園）。
園の行事は、どこで見られますか
「🏫スクール」タブの「📅園のカレンダー」です。予定を押すと 「📱 iPhone などのカレンダーに追加」「Google カレンダーに追加」から、スマホのカレンダーに入れられます。
園からのメッセージは、どこで読めますか
同じ「🏫スクール」タブの「💬園からの個人メッセージ」です。 読んだら「既読」を押していただくと、園の画面の未読数が減ります。「返信する」からお返事もできます。
きょうだいがいます。切り替えられますか
できます。アカウントはご家庭に1つで、画面の上の「お子さま」の右に、お名前のボタンが並びます。 押すと、連絡帳・写真・請求・身体記録がそのお子さまのものに切り替わります。
身長・体重が見られません
健康に関する情報なので、保護者ご自身の同意をいただくまで表示しません。 「内容を読んで同意する」を押していただくと出ます。同意は、あとから取り消すこともできます。
保育料の請求は、どこで見られますか。カードで払えますか
「👤マイページ」の「💴保育料のご請求」です。月ごとに金額・お支払期日・お支払いの状態が並びます。 園がカードでの受け取りを使っているときは、ここに「カードを登録する」が出て、支払期日に自動で引き落とされます。
出てこないときは、園の請求書の状態を見てください。「送付済」以降でないと保護者には見えません。
困ったときの相談先は、どこにありますか
「👤マイページ」の「🤝こまったときの相談窓口」です。園が「こども性暴力防止」の画面に入れた窓口が出ます。 園がアンケートを配信しているあいだは、マイページにそのアンケートも出ます。
買ったものが、いつ届くか分かりません
「👤マイページ」の「🧾購入履歴・配送状況」に、いまの状態が札で出ます。 園が「受け取りました」を押すまで「園の確認待ち」のままなので、届いたら押してください。
パスワードを忘れました
いまは、保護者ご自身では直せません。ログイン画面の「パスワードをお忘れですか？」は、 園につながったアカウントには使えません。園の管理者が「パスワードを作り直す」で新しい案内の紙をお渡しください（この手引きの01）。
ログインできなくなりました／「このアカウントは現在ご利用いただけません」と出ます
園でそのアカウントを止めているかもしれません。卒園・退園でないのに止まっている場合は、 園の管理者が「保護者アカウント新規発行」のタブで戻すを押してください。
アカウントを持っていない方でも使えますか
使えます。ログイン画面の「まずは教材だけ見てみる」から、 ストア・あそぶ・まなぶ・つながる・マイページが見られます。園に関するタブだけが休んだ状態になります。

05困ったとき

招待メールが届いていない、と言われた
その家庭の行を見てください。「送れませんでした」「期限（7日）が切れました」と出ていたら、 生徒情報のメールアドレスを確かめてから「招待を送り直す」を押します。メールの無いご家庭は、紙で発行してください。
保護者アカウントを発行しようとしたら「すでに登録されています」と出る
同じメールアドレスがすでに使われています。
「いま止めているアカウントで使われています」と出た場合は、止めている行の「戻す」を押してください。 新しく作り直す必要はありません。
保護者が「アプリに何も出ない」と言っている
発行のときに選んだ園児がちがっている可能性があります。 「保護者アカウント新規発行」のタブで、その行に出ている園児名をお確かめください。 ちがっていたら、いったん止めて、正しい園児で発行し直してください。
出品したはずの商品が保護者に出ない／出したくないものが出ている
商品は状態を入れないと公開扱いになります。逆に、記事・イベント・コミュニティは 公開にしないと出ません。同じ未来WAでも向きが逆なので、保存したあと保護者の画面で確かめてください。
未来WA の画面で、売上や名簿のところが出てこない
園の職員としてログインしているときだけ出ます。 Miralink にログインし直してから、「未来WA → 未来WA」を開き直してください。
保護者にアプリの入れ方をどう伝えればいいですか
メールのあるご家庭は招待メールがいちばん手間がかかりません。 メールの無いご家庭には、発行のときに出る「未来WA ご利用案内」の紙をそのままお渡しください。 二次元コード・メールアドレス・はじめのパスワードが1枚に載っています。
この手引きは 未来WA と Miralink の画面に合わせて作っています。画面が変わったときは、この手引きも新しくします。
ご不明な点は、Miralink の運営までお問い合わせください。
