# tools

## 規約とプライバシーポリシー

条文の**出どころは `parent.html` の `WA_LEGAL`** です。
公開ページ（`terms.html` / `privacy.html`）は、そこから作ります。

```bash
python3 tools/build-legal.py   # 公開ページを作り直す
node tools/check-legal.js      # 本文がずれていないか確かめる
```

**公開ページを手で直さないでください。** 直しても次の生成で消えますし、
アプリの中の同意画面（`parent.html`）とずれます。
条文を変えるときは `parent.html` の `WA_LEGAL` を直し、版（`WA_TERMS_VER`）を上げて、
`build-legal.py` を流してください。

`check-legal.js` は、見出し・本文・版の3つを突き合わせます。
ずれていると 1 を返して止まるので、公開前の確認に使えます。

## 直したあとの確認（index.html / parent.html）

```bash
node tools/lint.js index.html parent.html
node tools/smoke.js
```

**この2つは、直すたびに必ず流してください。**
2026-08-24 の1日で点検を6回まわし、出た食い違いは 100→37→31→34→51→53 件。
毎回50件ほど直すのに、そのうち10〜15件は**前の回の自分の直しが原因**でした。
その型が繰り返しだったので、機械で見つけられるようにしたのがこの2つです。

### `lint.js` が見るもの

| | 型 | 実際に起きたこと |
|---|---|---|
| ① | 定義が見当たらない名前を読んでいる | `present` の取り残しで、健康チェックが管理者でも一般でも一度も開けなくなった |
| ② | 同名のトップレベル関数が2つ | `renderTimecard` `auditFY` `lockSnap` で3回。後勝ちで古い方が動き、直しても何も変わらない |
| ③ | 引数を増やした関数を、古い数で呼んでいる | クラス名の付け替えで、連れていくはずの記録が漏れた |

文字列・コメント・正規表現は1文字ずつ読み飛ばすので、`'<div id="x">'` の
`x` を名前と誤解しません。`Object.defineProperty(window,'CLASSES',…)` で
作っている名前も分かります。**3つともゼロでないと直し終わりではありません。**

### `smoke.js` が見るもの

31画面を開くだけでなく、**記録の種類（日常4つ＋活動記録）とシフトのタブを、
管理者（`cocoas_staffSession=1`）と一般（`=3`）の両方で開いて回ります。**
画面を開くだけの検査では、上の①（健康チェックが開かない）を見つけられませんでした。

権限で開けない画面と、section を持たない `creator`（別ファイルを開くだけ）は除きます。
配信は `python3 -m http.server 8899` が要ります。
