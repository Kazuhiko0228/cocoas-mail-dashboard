未来WA ／ 園の管理者向け

未来WA 管理者の手引き

未来WA は、保護者の方がスマートフォンで使うアプリです。 園からの連絡・お子さまの記録・教材やイベントが、ここに集まります。
園の操作は、すべて EduGrow の画面から行います。保護者にアプリを配るところから、 日々の運用、聞かれたときの答え方までをまとめました。
株式会社BIM JAPAN　／　2026年9月版

01はじめる ── 保護者にアプリを届ける

未来WA は、保護者がログインできて、はじめて動きだします。 ここがいちばん大事な最初の一歩です。園児1人につき1つ、アカウントを発行します。

保護者アカウントを発行する管理者だけ

  1. EduGrow の「連絡・配信 → 未来WA」を開く
  2. いちばん下の保護者アカウントのカードまで下げる
  3. 「新しく発行する」で園児を選び、保護者のメールアドレスとはじめのパスワード（8文字以上）を入れて発行する
  4. 出てきた窓に、保護者にお伝えする3つが並びます。園コード／メールアドレス／パスワード
  5. この3つを、園から保護者へ直接お伝えする（紙・口頭・園のLINEなど）
メールは自動では送られません。お渡しは園から直接お願いします。
園児を選ぶ欄には、まだアカウントの無いお子さまだけが並びます。二重に発行してしまうことはありません。
保護者は、最初のログインでご自身のパスワードに変えていただきます。

まだ入っていない家庭を見つける管理者だけ

  1. 同じカードの上に「◯家庭が、まだ一度も入っていません」と出ます
  2. その家庭の行には「まだ一度も入っていません」と橙色で出ています
  3. IDが渡っていないか、入りかたが分からずにいるかもしれません。声をかけてください
「初期パスワードのまま」と出ている家庭は、入れてはいるけれど、 まだご自身のパスワードに変えていない状態です。

パスワードを忘れた、と言われたら管理者だけ

  1. その家庭の行のパスワードを作り直すを押す
  2. 新しいパスワード（8文字以上）を入れる。いまのパスワードは分からなくて構いません
  3. 出てきた窓の内容を、保護者にお伝えする
保護者は、次のログインで必ず変更を求められます。 これまでの注文・申込・連絡の記録は、そのまま残ります。

卒園・退園したとき管理者だけ

  1. その家庭の行の止めるを押す
  2. 保護者は未来WAに入れなくなります。記録は消えません
  3. 戻ってこられたときは、同じ行の戻すを押すだけです

02ふだんの運用 ── 園から保護者へ

保護者は未来WAのアプリ1つで受け取ります。 送る操作は、すべて EduGrow の画面から行います。 「連絡・配信 → 未来WA」の一覧の「ひらく」を押すと、その画面へ移ります。
保護者に届くものEduGrow のどこから送るか
おたより・お知らせ連絡・配信 → 全体周知・お知らせ
園からの個人メッセージ連絡・配信 → 保護者DM
出欠・連絡（保護者から園へ）ホーム／日常チェックに自動で入ります
成長の記録（身長・体重）保育記録 → 身体測定
スクールガイド（入園時の一式）設定・その他 → スクールガイド
保育料のご請求顧客情報・料金管理 → 請求書発行
教材・イベント未来WA の画面（次の章）

お知らせが保護者に出てこない、と言われたら全員

  • お知らせは、状態が「公開」のものだけが保護者に出ます。
  • 保護者DMは、下書き・園内の申し送りは届きません。送信済のものだけです。
  • ご請求は「送付済」「入金済」になってはじめて保護者に見えます。 「発行済」の段階では、まだ見えていません。
「届かない」の相談は、まずこの3つの状態を見てください。

保護者から届いたものを受け取る全員

  1. 欠席・遅刻・お迎え時間の変更　日常チェックの登園（出席）に、空欄のときだけ自動で入り「保護者」の印が付きます
  2. 保護者からのメッセージ　保護者DM に届きます
  3. 教材の注文・イベントの申込　未来WA の「売れたもの」「イベント」に届きます
先生が入れた出欠の印は、保護者からの連絡で書き換わりません。 食いちがうときは「連絡は欠席」のような赤い印が出ます。どちらが正しいかは、園でご判断ください。

03未来WA の画面 ── 教材・イベント

「連絡・配信 → 未来WA」の未来WA を開くで、別のタブに開きます。 商品を出す・イベントを出す・売れたものを見る、はこちらの画面です。

教材・用品を出品する全員

  1. 左の一覧から「ショップ出品」を開く
  2. ＋ 商品を出品を押す
  3. カテゴリ・商品名・説明・価格を入れる
  4. 「売り方」を選ぶ（単品で売る／毎月おとどけ／貸し出す）
  5. 園だけの欄「ねらい」「今月のおすすめ」「見せる相手」「写真」を入れる
  6. 公開する、またはまだ出さないなら下書きに保存
下書きのつもりでも、状態を入れずに保存すると保護者に見えます。 出したくないものは、必ず「下書きに保存」を選んでください。

園のおすすめを、保護者のストアのいちばん上に並べる全員

  1. 「ショップ出品」の上のほうの「園のおすすめの並び」の表を見る
  2. 出したい商品の「見せる」にチェックを入れ、「順番」に数字を入れる
  3. 必要なら「ご用意のお願い」（例：入園までにご用意ください）を書く
  4. この内容で保護者に見せるを押す

イベントを出す・申込の名簿を見る出すのは全員／名簿は園長・管理者

  1. 「イベント」を開き＋ イベントを作成
  2. 対象者（親子／保護者向け／子供向け）、テーマまたは種別、対象の年齢を選ぶ
  3. タイトル・内容・開催日・定員・場所・参加費を入れて公開する
  4. 申し込みは、そのイベントの行の申込の名簿で見られます
お申し込みのお名前が見られるのは園長・管理者だけです。先生には件数だけが出ます。

売れたものを確かめて「受け取りました」を押す全員

  1. 「売れたもの」を開く
  2. 売れた金額・園への還元・まだ確認していない注文の数を見る
  3. 注文の明細で、日時・園児・商品・金額を確かめる
  4. 品物が園に届いたら、その行の受け取りましたを押す
この操作をすると、保護者の画面が「園で受け取りました」に変わります。 押さないと、保護者はいつまでも「園の確認待ち」のままです。
園への還元率（0〜50）も、この画面で決めて保存します。

ダウンロード教材のファイルを預ける園長・管理者

  1. 商品のカテゴリを「ダウンロード教材」にして、先に公開または下書きに保存する
  2. その商品を「編集」で開き直し、「お渡しするファイル」でPDF・PNG・JPEG（4MBまで）を選ぶ
  3. 「お渡しできる日数」と「受け取れる回数（1家庭）」を入れる
  4. このファイルを預けるを押す
預けられるのは園長・管理者だけです。先生の画面では断られます。
保護者は、その教材を買った家庭だけが受け取れます。

04保護者に聞かれたら

保護者のアプリには、下に5つのタブ（花びら）が並んでいます。 🏫スクール／🎨あそぶ／🌱まなぶ／🛍️ストア／🤝つながる。 園に関することは、いちばん左の「スクール」に集まっています。
おやすみの連絡は、どこからしますか
「🏫スクール」タブのいちばん上、「📅出欠・連絡」です。 日付と区分（欠席／送迎時間変更）を選び、事情を書いて送っていただきます。 送った控えと園からの返信は、その下の「🗒連絡の履歴」に残ります。
園からのメッセージは、どこで読めますか
同じ「🏫スクール」タブの真ん中、「💬園からの個人メッセージ」です。 読んだら「既読」を押していただくと、園の画面の未読数が減ります。「返信する」からお返事もできます。
きょうだいがいます。切り替えられますか
できます。画面いちばん上の「お子さま」の右に、お名前のボタンが並びます。 押すと、連絡帳・写真・請求・身体記録がすべてそのお子さまのものに切り替わります。
身長・体重が見られません
健康に関する情報なので、保護者ご自身の同意をいただくまで表示しません。 「👤マイページ」の赤い枠から「内容を読んで同意する」を押していただくと出ます。 同意は、あとから取り消すこともできます。
保育料の請求は、どこで見られますか
「👤マイページ」の「💴保育料のご請求」です。 月ごとに金額・お支払期日・「お支払い済み／お支払いのお願い」が並びます。
出てこないときは、園の請求書発行の状態を見てください。「送付済」以降でないと保護者には見えません。
買ったものが、いつ届くか分かりません
「👤マイページ」の「🧾購入履歴・配送状況」に、いまの状態が札で出ます。 「園に配送中」→「園で受け取り済み」の順に変わります。 園が「受け取りました」を押すまで「園の確認待ち」のままなので、届いたら押してください。
パスワードを忘れました
アプリのログイン画面に「パスワードをお忘れですか？」があり、 メールアドレス → 6桁の確認コード → 新しいパスワード の順でご自身で直せます。
うまくいかないときは、園の管理者が作り直せます（この手引きの01をご覧ください）。
アプリに「このアカウントは現在ご利用いただけません」と出ます
園でそのアカウントを止めています。卒園・退園でないのに出ている場合は、 園の管理者が「連絡・配信 → 未来WA → 保護者アカウント」で戻すを押してください。
アカウントを持っていない方でも使えますか
使えます。ログイン画面の「まずは教材だけ見てみる」から、 ストア・あそぶ・まなぶ・つながる・マイページが見られます。園に関するタブだけが休んだ状態になります。

05困ったとき

保護者アカウントを発行しようとしたら「すでに登録されています」と出る
同じメールアドレスがすでに使われています。
「いま止めているアカウントで使われています」と出た場合は、止めている行の「戻す」を押してください。 新しく作り直す必要はありません。
保護者が「アプリに何も出ない」と言っている
発行のときに選んだ園児がちがっている可能性があります。 「保護者アカウント」のカードで、その行に出ている園児名をお確かめください。 ちがっていたら、いったん止めて、正しい園児で発行し直してください。
出品したはずの商品が保護者に出ない／出したくないものが出ている
商品は状態を入れないと公開扱いになります。逆に、記事・イベント・コミュニティは 公開にしないと出ません。同じ未来WAでも向きが逆なので、保存したあと保護者の画面で確かめてください。
未来WA の画面で、売上や名簿のところが出てこない
園の職員としてログインしているときだけ出ます。 EduGrow から「未来WA を開く」で開き直してください。
保護者にアプリの入れ方をどう伝えればいいですか
お伝えいただくのは3つだけです。園コード・メールアドレス・パスワード。 発行のときに出る窓の内容を、そのまま紙にして配るのがいちばん確実です。
